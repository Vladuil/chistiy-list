# 🌿 Чистый Лист — Трекер отказа от вредных привычек и развития

**«Чистый Лист»** — это веб-приложение для избавления от вредных привычек и выработки полезных ежедневных ритуалов (чтение книг, спорт, обучение) с поддержкой личных аккаунтов, живых таймеров и общего «Зала славы» для друзей и близких.

## 🚀 Пошаговая инструкция: Как запушить проект на GitHub

### Шаг 1. Сохраните файлы проекта в одну папку на компьютере

Создайте на компьютере новую папку (например, `chistiy-list`) и сохраните в неё все **8 файлов** из редактора:

1. `habit_tracker.html`
2. `server.js`
3. `package.json`
4. `docker-compose.yml`
5. `nginx.conf`
6. `.gitignore` *(обратите внимание на точку в начале имени файла)*
7. `.env.example` *(точка в начале имени файла)*
8. `README.md`

### Шаг 2. Создайте пустой репозиторий на GitHub

1. Зайдите на [github.com](https://github.com/) и войдите в свой аккаунт.
2. В правом верхнем углу нажмите **`+`** → **New repository** (или перейдите на [github.com/new](https://github.com/new)).
3. В поле **Repository name** введите название, например: `chistiy-list`.
4. Выберите видимость: **Public** (публичный) или **Private** (приватный — если хотите, чтобы код видели только вы).
5. **Важно:** Не ставьте галочки на *«Add a README file»* и *«Add .gitignore»*, так как эти файлы у нас уже готовы.
6. Нажмите зелёную кнопку **Create repository**.

### Шаг 3. Загрузите файлы на GitHub (выберите удобный способ)

#### Вариант А: Через терминал (Git) — классический способ

1. Откройте терминал (**Git Bash** на Windows, **PowerShell** или **Terminal** на macOS/Linux) внутри вашей папки `chistiy-list`.
2. Выполните по очереди следующие команды (замените ссылку в 5-й команде на ссылку вашего репозитория):

```bash
# 1. Инициализируем Git в папке
git init

# 2. Добавляем все файлы к коммиту
git add .

# 3. Создаём первый коммит
git commit -m "Initial commit: Chistiy List habit tracker with Docker & PostgreSQL"

# 4. Переименовываем основную ветку в main
git branch -M main

# 5. Привязываем ваш репозиторий GitHub (подставьте свою ссылку!)
git remote add origin https://github.com/ВАШ_ЛОГИН/chistiy-list.git

# 6. Отправляем файлы на GitHub
git push -u origin main
```

#### Вариант Б: Без терминала (прямо через браузер за 1 минуту)

1. На странице только что созданного пустого репозитория на GitHub найдите синюю ссылку **«uploading an existing file»** (в блоке *Quick setup*).
2. Выделите все 8 файлов в вашей папке на компьютере и перетащите их мышкой в окно браузера.
3. Подождите пару секунд, пока файлы загрузятся, и внизу нажмите зелёную кнопку **Commit changes**.

## 🌐 Как развернуть проект на своём сервере (VPS) из GitHub

1. Подключитесь к серверу по SSH и склонируйте ваш репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/chistiy-list.git
   cd chistiy-list
   ```
2. Создайте файл `.env` из шаблона и впишите свой надёжный пароль для базы данных PostgreSQL:
   ```bash
   cp .env.example .env
   nano .env
   ```
3. Запустите все контейнеры в фоновом режиме:
   ```bash
   docker compose up -d
   ```
